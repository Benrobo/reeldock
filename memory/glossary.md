# Glossary

| Term                | Meaning                                                                                       |
| ------------------- | --------------------------------------------------------------------------------------------- |
| ReelDock project    | A `.reeldock` folder containing `project.json`, source media files, thumbnails, and exports   |
| Phone source        | The connected iPhone video capture stream                                                     |
| Webcam source       | The selected Mac or external camera stream                                                    |
| Microphone source   | The selected audio input stream                                                               |
| Layout-first editor | An editor focused on canvas ratio, position, size, background, trim, audio volume, and export |
| Source offset       | The source start time relative to the shared project timeline                                 |
| Native helper       | The macOS process or module that performs AVFoundation capture and rendering work             |
| Recovery            | Preserving usable media segments after a crash, disconnect, or helper failure                 |
